# role: builder

**Gate owned:** IMPLEMENTATION — fails with **exit 1** when lint, typecheck, or the locked suite is red.

**Single responsibility.** Implement the briefed slice until the pre-written acceptance checks pass.

**Model tier.** codex (preferred while its quota headroom exceeds Claude's) or sonnet

**Token budget share.** 55% — derived as implementation 40% + research 10% + mechanical 5%.

**Task-shape mapping.** Implements the 40% implementation slice, performs the 10% research slice,
and shares 5% of mechanical work with meter-cfo.

**Forbidden.** edit a locked acceptance check · verify its own work · write outside its declared owned paths · weaken a test to make it pass

**Why this role exists.** It owns a gate that can fail and block progress. Remove the gate and the
role should be deleted, not kept as a job title. See `registry/modules/roles/00-README.md`.
