# LLD node completion ledger

This ledger is the handoff point for the one-node-at-a-time L8 pass. It records
the original Fleet requirement, evidence, real-user prompts, fixes, and gates.

## Product requirement understood

Fleet is a local CLI SDLC harness: accept user or authorized connector work,
normalize and durably record it, classify and route it deterministically, run
bounded isolated agents, independently verify their work, repair or escalate
on evidence, and stop before external publication unless the exact action is
approved. Model prose is never proof. Every refusal and verdict needs a durable
receipt and a nonzero checked/total denominator.

## Operating contract

- One LLD node at a time; do not mark complete without implementation, security,
  performance, edge-case, real-binary, and user-DX evidence.
- Use `./dev.sh` and enter adversarial prompts as a real user.
- Fix findings in Fleet, then repeat the failing prompt and relevant gates.
- Preserve unrelated dirty work. Never edit authored acceptance tests.
- Status values: `not-started`, `in-progress`, `blocked`, `complete`.
