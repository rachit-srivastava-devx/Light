# B19 — codex-tick.sh sed portability fix (closes T6's last hit)

## What happened

`bin/codex-tick.sh:43` used `sed -i ''` which is BSD-only (macOS native sed). GNU sed 4.10
(brew-installed `gsed`) treats `''` as the script and the next word as a filename — `rc=2`,
file unedited. This is the same bug class as B17b's fix in `bin/codex-fanout.sh:43,107`,
which was already approved, applied, and verified on both native BSD sed and GNU sed.

## The fix

Replaced the BSD-only `sed -i ''` with the portable temp-file pattern already approved in
B17b:

```
# Before (BSD-only):
sed -i '' "s|^## \[ \] $ID |## [~] $ID |" handover/BACKLOG.md 2>/dev/null || true

# After (portable, same pattern as codex-fanout.sh):
sed "s|^## \[ \] $ID |## [~] $ID |" handover/BACKLOG.md > handover/BACKLOG.md.tmp && mv handover/BACKLOG.md.tmp handover/BACKLOG.md 2>/dev/null || true
```

One line, mechanical, identical to the B17b fix — same owner-authorized fix class, extended
to the sibling file with the identical bug.
