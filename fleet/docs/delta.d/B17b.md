## Task 1: T6 — BSD vs GNU sed in bin/codex-fanout.sh

**Before (B17 baseline):** T6 fired on 3 `sed -i ''` lines — `bin/codex-fanout.sh:43,107` and
`bin/codex-tick.sh:43`. BSD `sed -i '' "s|...|...|" file` works natively on macOS; GNU sed
(installed via `brew` as `gsed` at `/opt/homebrew/bin/gsed`) treats `''` as the script argument
and the next word as the filename → `rc=2`, file unedited. On Linux CI (GNU sed), the two
`codex-fanout.sh` sites would silently stop marking backlog items [~] or [x].

**Fix (2 lines changed, both in `bin/codex-fanout.sh`):** replaced each `sed -i ''` with a
portable temp-file pattern:

```
# Line 43 (launch: mark item in-progress)
-  sed -i '' "s|^## \[ \] $ID |## [~] $ID |" handover/BACKLOG.md 2>/dev/null
+  sed "s|^## \[ \] $ID |## [~] $ID |" handover/BACKLOG.md > handover/BACKLOG.md.tmp && mv handover/BACKLOG.md.tmp handover/BACKLOG.md 2>/dev/null

# Line 107 (commit block: mark item done)
-  [ "$verdict" = "DONE" ] && sed -i '' "s|^## \[~\] $ID |## [x] $ID |" handover/BACKLOG.md
+  [ "$verdict" = "DONE" ] && sed "s|^## \[~\] $ID |## [x] $ID |" handover/BACKLOG.md > handover/BACKLOG.md.tmp && mv handover/BACKLOG.md.tmp handover/BACKLOG.md
```

**Before proof:**
```
$ gsed -i '' "s|^## \[ \] B17 |## [~] B17 |" handover/BACKLOG.md
gsed: can't read s|^## \[ \] B17 |## [~] B17 |: No such file or directory
$ echo $?
2
```

**After proof — native BSD sed:**
```
$ ID=B17 && cp handover/BACKLOG.md /tmp/t.md && sed "s|^## \[ \] $ID |## [~] $ID |" /tmp/t.md > /tmp/t.md.tmp && mv /tmp/t.md.tmp /tmp/t.md && grep "## \[~\] B17" /tmp/t.md
## [~] B17 — Triage and safely fix the last seven pre-existing corpus catches ...
```

**After proof — GNU sed:**
```
$ ID=B17 && cp handover/BACKLOG.md /tmp/t.md && gsed "s|^## \[ \] $ID |## [~] $ID |" /tmp/t.md > /tmp/t.md.tmp && mv /tmp/t.md.tmp /tmp/t.md && grep "## \[~\] B17" /tmp/t.md
## [~] B17 — Triage and safely fix the last seven pre-existing corpus catches ...
```
