# Fleet v0.1.1

Date: 2026-09-15

## What changed

This release makes the local development loop native to Apple Silicon and makes execution
explainable against `docs/LLD/`.

### Development and build system

- `dev.sh` selects `stable-aarch64-apple-darwin` when available.
- Native build output is isolated at `target/aarch64-apple-darwin`.
- `scripts/fleet-build.sh` uses the same native toolchain selection.
- `sccache` is disabled by default because the ARM64 wrapper stalled while invoking the installed
  x86_64 toolchain; opt in only with `FLEET_USE_SCCACHE=1`.
- `cargo-watch` uses `--shell "bash scripts/fleet-build.sh"`.
- Watcher adoption and failure output now point to the correct log file.
- `./dev.sh watch` keeps the terminal attached to the watcher.

### Execution trace

- `Event::LldPathStep` renders one numbered line per LLD path node.
- Pipeline stages print their actual connected path, including explicit stub and unwired markers.
- Durable-resumed stages print the same path with a resume note.
- Interactive answers print their direct path and explicitly identify the pipeline bypass.

The trace is intentionally implementation-honest: it names only paths the current composition
root actually traverses. A design node that is not wired is printed as `not wired`, `stub`, or
`not traversed`; it is never presented as executed.
