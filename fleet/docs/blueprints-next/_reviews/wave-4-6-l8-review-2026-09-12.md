## 3. P0 Findings (block merge)

### P0-1: notify — 20 surviving mutations, stub-safe tests only
**Location:** `crates/notify/tests/notify.rs`  
**Root cause:** Tests use `assert!(receipt.checked > 0)` and `assert!(!n.payload.is_empty())` — these are proxy assertions that don't pin exact values. A mutation changing `checked: 1` to `checked: 0` kills the test, but changing `attempts: 0` to `attempts: 99` does not.  
**Required fix:** Pin exact values with `assert_eq!`. Test `build_delivery_receipt` with values that distinguish `delivery_attempts.min(total_recipients)` from identity mutations.

### P0-2: rollback — CAS and containment guards not independently tested
**Location:** `crates/rollback/tests/rollback.rs`  
**Root cause:** Existing tests cover `ArtifactNotFound` and containment, but the `PrivateRef` CAS path (`check_cas`) has no direct test. The mutation `applied == head` → `applied != head` survives.  
**Required fix:** Test `PrivateRef` with mismatched `applied` hash to exercise `CasMismatch`. Test `SharedRef` path exists.

### P0-3: notify — PII redaction not pin-tested
**Location:** `crates/notify/src/redact.rs`  
**Root cause:** Test `sensitive_fields_not_in_notification` asserts the raw email is absent, but doesn't verify what the redacted form IS. Mutation replacing `redact_pii` with identity function would still pass (because the redacted text doesn't literally contain the email format either).  
**Required fix:** Assert the redacted payload equals an exact expected string, or assert `derive_idempotency_key` output is stable across equal inputs and differs across different inputs.

### P0-4: notify — idempotency key derivation not pin-tested
**Location:** `crates/notify/src/redact.rs:derive_idempotency_key`  
**Root cause:** The FNV-1a hash for idempotency is only implicitly tested via `Conflict` on duplicate. A mutation changing the hash algorithm (XOR one byte) survives because both inputs are identical — the test only checks that duplicate = conflict, not the key VALUE.  
**Required fix:** Pin the exact idempotency key for a known (task_id, transport, recipient, payload) input.
